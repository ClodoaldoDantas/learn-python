# Aprendendo Python

Projeto com exemplos simples para praticar conceitos básicos de Python.

## Como executar

É necessário ter Python 3 instalado. No terminal, execute um exemplo a partir da pasta do projeto:

```bash
python3 01-variables/main.py
```

Substitua `01-variables/main.py` pelo caminho do exemplo que deseja executar. Alguns exemplos pedem dados pelo terminal.
